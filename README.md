# SysMonitor · 系统监控小工具

一个常驻桌面边缘的 Windows 系统监控工具：实时显示进程 CPU / 内存 / 网络占用，CPU / GPU 频率与温度、风扇转速，支持一键杀进程、进程筛选与批量结束、按 CPU / 内存排序，并可从底层传感器读取硬件温度与风扇数据。

纯 C# / WinForms 编写，单项目、零第三方依赖，`dotnet publish` 即可出单文件 exe。

---

## 功能特性

### 硬件监控（实时）
| 类别 | 指标 |
|---|---|
| CPU | 占用率、当前频率（GHz）、温度 |
| GPU | 占用率、核心频率、温度、显存占用 |
| 内存 | 已用 / 总量 / 百分比，附带**实时进度条**（绿 <60% / 黄 60~85% / 红 >85%） |
| 网络 | 实时下行 / 上行速度（MB/s） |
| 风扇 | CPU 风扇、显卡风扇、机箱风扇转速（RPM） |
| 调速 | 风扇转速调节滑杆（20%~100%），支持的主板可实时调速 |

### 进程管理
- 实时进程列表（PID / CPU% / 内存 / 线程），每 2 秒刷新
- **按 CPU / 按内存** 一键排序（筛选栏右侧按钮，蓝色高亮当前排序）
- 一键结束：行尾红色【结束】按钮 / 右键菜单「结束进程」「结束进程树」
- **进程筛选**：输入关键词即时过滤（最多 100 条）
- **【结束全部】**：一键结束所有匹配筛选关键词的进程，先弹确认框再批量直杀
- 右键进程菜单：结束进程 / 结束进程树 / 打开所在文件夹 / 复制路径 —— 便于追溯进程来源（查流氓软件）

### 桌面交互
- **屏幕边缘自动隐藏**：鼠标移开约 2.5 秒后收起为屏幕边缘一个小圆点（绿色指示灯）；鼠标移上自动展开，平时不挡桌面
- **固定窗口**：📌 图钉按钮 / 托盘右键菜单可固定窗口，永不自动收起
- **可拖动**：拖动标题栏移动窗口，松手自动吸附最近的屏幕边缘，位置记忆
- 最小化到托盘、完全退出

## 项目结构

```
SysMonitor/
├── Program.cs          # 入口：管理员权限请求 + 启动主窗体
├── Form1.cs            # 主窗体：UI 构建、硬件/网络渲染、进程列表、杀进程、边缘折叠交互
├── ProcessScanner.cs   # 进程扫描：CPU%、内存、线程、PID 采集与排序
├── SensorReader.cs     # 硬件传感器：CPU/GPU 温度、频率、显存、风扇转速读取
├── app.manifest        # UAC 管理员权限清单（读硬件传感器需要）
├── app.ico             # 应用图标
└── SysMonitor.csproj   # 项目文件（net8.0-windows / WinForms，单文件发布配置）
```

## 技术栈

- **语言 / 框架**：C# / .NET 8 / WinForms
- **硬件数据**：Windows 性能计数器（PerformanceCounter）+ WMI + 底层传感器读取（管理员权限）
- **进程操作**：`System.Diagnostics` + 原生 `OpenProcess/TerminateProcess`
- **零第三方依赖**：不引用任何 NuGet 包，构建即用

## 构建方法

环境要求：.NET 8 SDK（Windows）

```bash
# 调试运行
dotnet run

# 发布为单文件 exe（免安装，直接拷走用）
dotnet publish -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true \
  -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:EnableCompressionInSingleFile=true \
  -p:DebugType=None -p:DebugSymbols=false \
  -o dist
```

产物：`dist/SysMonitor.exe`（约 50MB，自包含运行时）。

## 使用说明

1. **首次启动**会弹出 UAC 管理员授权，请点【是】——读取 CPU/GPU 温度、风扇转速等硬件传感器需要管理员权限；不给则温度/风扇显示 `—`。
2. 若出现 SmartScreen 提示，点【更多信息】→【仍要运行】（未签名程序属正常）。
3. **开机自启**：`Win+R` 输入 `shell:startup` 回车，把 `SysMonitor.exe` 的快捷方式放进去即可。

### 交互细节
- 鼠标移开窗口约 2.5 秒后收起为屏幕边缘小圆点；鼠标移到圆点上自动展开
- 📌 图钉：固定 / 取消固定（固定后不自动收起，适合慢慢操作）
- 进程列表右键：结束进程 / 结束进程树 / 打开所在文件夹 / 复制路径
- 顶部筛选框输入关键词 → 即时过滤；【结束全部】批量结束匹配进程

### 数据说明
- 进程 CPU% 为占整机总 CPU 的百分比
- CPU 频率/温度、主板风扇依赖硬件支持（部分主板 BIOS 或虚拟机不提供），读不到时显示 `—`，属正常
- 调速滑杆：仅主板/CPU 风扇可软件调速；若显示「本机不支持」，说明主板 BIOS 未开放调速通道（笔记本/部分主板常见），显卡风扇由显卡驱动独占管理
